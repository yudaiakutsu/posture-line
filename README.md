# 姿勢ライン (PostureLine)

撮影した身体の写真に**赤い重心線・グリッド**を引き、**傾き補正**と**トリミング（印刷範囲指定）**をして、印刷用の画像として書き出す、完全オリジナルの個人用Webアプリ（PWA）。AIによる自動分析は行わず、線を自分で合わせるシンプルな姿勢チェック用ツールです。

クラベール等の姿勢分析アプリのような「写真＋基準線」を、オフライン・無料で実現します。

## できること

- **2枚を1枚のA4に合成**: ①前額面・②矢状面の2枚を整え、**横向きA4 1枚に左右並べて**書き出す（見出し「前額面/矢状面」＋日付つき、白背景・300dpi相当）
- **写真の取り込み**: カメラ撮影 or 写真ライブラリから選択（スロット①②を切り替えて各々読み込み）
- **傾き補正**: ±20°・0.1°刻みで水平を出す
- **重心線**: 画面に対して垂直な赤線。指でドラッグして左右に微調整（垂直のまま）
- **グリッド**: 赤い格子をオーバーレイ。縦線は重心線を中心に左右対称、横線は上下対称。間隔調整可
- **構図**: 写真を指でなぞって移動・ピンチで拡大。編集枠の縦横比はA4セルと同じなので、画面で見たまま印刷される
- **保存**:「A4保存」→ プレビュー表示 →「写真に保存」でカメラロールへ
- **オフライン動作**: 一度読み込めばネット非接続でも使用可（PWA）

## 印刷の流れ（ネット非接続前提）

1. アプリで赤線・トリミングを仕上げて「保存」→ iPhoneのカメラロールに画像が入る
2. iPhoneをPCに**有線接続**して画像をコピー
3. PCから有線プリンタで印刷

## iPhoneで使う（GitHub Pages）

同じWi-Fiに接続する必要はなく、ネットに繋がっていればどこからでもアクセスできる。

1. iPhoneのSafariで https://yudaiakutsu.github.io/posture-line/ を開く
2. 共有ボタン →「ホーム画面に追加」でアプリのように起動
   （一度読み込めば**オフラインでも動作**するので、その後はネット不要）

コードを更新したら `git push` するだけで、数分後に上記URLへ反映される
（GitHub Pages: Settings → Pages、`main`ブランチのrootを配信）。

## 開発時（Mac上で動作確認）

```sh
cd ~/posture-line
python3 -m http.server 8124
```

ブラウザで http://localhost:8124 を開く。

同一Wi-Fi内であれば iPhone の Safari から `http://<MacのIPアドレス>:8124`
（IPアドレスは `ipconfig getifaddr en0` で確認）でも確認できるが、
Macが実際の家庭用Wi-Fiに接続されておらず「iPhoneの個人ホットスポット」経由になっていると
（`en0`のIPが`192.0.0.2`等になる）、iPhone側からMacへは繋がらないので注意。
迷ったら上記のGitHub Pages版を使うのが確実。

## 操作のコツ

- **重心線を動かす**: 赤線の近くを指で掴んでドラッグ
- **写真を動かす**: 線から離れた場所を指でなぞる（パン）
- **拡大/縮小**: 2本指ピンチ、または右下の ＋／－、⤢で全体表示に戻す
- **傾き**: 「傾き」タブのスライダー、または 0.1°ボタンで微調整

## ファイル構成

- `index.html` / `style.css` … 画面とUI
- `js/app.js` … 描画・ジェスチャー・傾き補正・書き出しの本体
- `manifest.webmanifest` / `sw.js` / `icon-*.png` … PWA（ホーム画面アプリ化・オフライン対応）

更新したら `sw.js` の `CACHE` のバージョン番号を上げると確実に反映されます。
